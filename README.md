# Kelire · 桌面动漫下载器

> 仓库地址：<https://github.com/Yelastforbilibili/Kelire>

面向 Windows 的个人向动漫下载与观看工具：从天天动漫的镜像站取数据，内置多线程 HLS 代理让在线观看不受原站单连接限速的影响，同时支持按集把视频下载到本地。

## 运行

只需要 Python 环境，不用打包：

```
pip install -r requirements.txt
python run.py
```

或者手动装依赖：

```
pip install PySide6 yt-dlp pycryptodome imageio-ffmpeg requests pillow
```

也可以双击 `start.bat`（自动找 `pythonw.exe` 静默启动，不弹黑框）。

- Python 3.10 及以上
- 只在 Windows 上测过，其它平台没有适配
- 想做成 exe 时见下方「打包」一节的命令

首次启动会先出现两步引导：免责声明（必须停留 5 秒才能勾选）和小贴士，读完并分别确认后才进入主界面；之后不再弹出，需要重看时到「设置 → 重置与修复 → 重新查看免责声明与小贴士」。

## 功能

- 启动时读取 `https://www.ttdm0.me/` 发布页里列出的镜像并测速，自动选延迟最低的可用线路；后台按设置里的间隔（默认 5 分钟）重新测速刷新，某个域名挂了会自动换下一个
- 首页：今日推荐轮播 + 正在热播 + 六个分类横向片单，「继续观看」回到上次的集数和进度
- 搜索：按名字/角色/年份搜索，分页，卡片进入详情；调试模式改动会立刻作用到已有结果，不用重新搜一次
- 详情：封面、年份/地区/分类、别名/导演/声优/语言、简介折叠、线路与剧集列表；点剧集才播放，不会一进页面就开始播
- 在线观看：内置本地 HLS 代理，多线程并发预取加密分片并落盘缓存，拖进度条走本地缓存；倍速、音量、全屏、选集抽屉、自动下一集、记住进度；退出播放页会立即停止播放
- 缓冲条：进度条下面紧挨一条细白条，已经拉好的分片对应的时段显示成白色，和平时看视频的缓冲进度一样，按本地缓存实时刷新
- 剧集预加载：播放页的剧集列表里，鼠标移到某一集右侧会渐显一个「+」（鼠标像手电筒一样照亮一行），点一下就把这一集的开头百分之几提前拉进播放缓存，最多同时选 3 集（可在设置里改 1–6 集、5%–50%）。排队按剧集顺序一集一集来，单集内部并发拉取但只占 4 个连接，不会抢正在播放那一集的带宽；正在播放的剧集不能选，切集时会自动退出预加载。选中的那一行会直接显示预加载进度（进度条从右往左，文字压在进度条上面）
- 拖进度条：目标分片会被提到下载队首，旧位置的预取任务直接作废；播放器偶尔会把跳转丢掉（看起来像回到开头），程序会自动再跳一次，必要时带着目标位置重连本地清单
- 下载：先弹选集框确认要下哪几集（默认全选，可全选/全不选/只选未看），再按线路下载；单集并发分片数与同时下载集数可调；下载管理页有进度/速度/剩余时间、取消（取消即移除卡片）、重试、打开文件位置；已完成记录持久化且可单独删除
- 分类片库：首次进入某个分类后把结果留在内存里，来回切换是瞬间打开；右上角「刷新」会丢掉缓存重新拉第一页。缓存可以在设置里关掉
- 外观：深色用克制的播放红，浅色换成沉稳的靛蓝（红配白太扎眼）；设置里可以自定义强调色（6 个预设 + 取色器，深浅色各记一个）
- 动效：切页面是旧页面截图交叉淡出，切主题/换强调色整个窗口交叉淡出，设置面板折叠是手风琴式高度动画，剧集抽屉从右侧滑入，封面、下载行、剧集网格都是淡入；设置里可以一键关掉所有动效
- 多语言：中文/英文即时切换，界面文案都在语言文件里维护（见下方「多语言」）
- 设置：所有大项都可以点标题折叠/展开（折叠状态在本次运行内记住）；右上角有设置项搜索框，输入关键词（比如「缓存」「线路」）只留下相关条目，命中的面板会自动展开；分外观与语言、下载、导航与分类、播放、站点线路、缓存与数据、重置与修复、关于几个面板

下载文件名由模板决定，默认 `{集数}`，也可写成 `{名字} {集数}` 之类；可用占位符：`{名字}`、`{集数}`、`{集号}`、`{总数}`、`{线路}`（英文别名 `{name}`、`{episode}`、`{index}`、`{total}`、`{source}`）。下载目录默认是程序根目录下的 `downloads/动漫名/`，可以在设置里改到任意位置。

## 调试模式

设置 → 外观与语言 → 「调试模式：隐藏番剧名称与封面」。打开后：

- 所有片单、详情、继续观看、下载记录里的番剧名都变成「番剧 01」「番剧 02」这类固定别名，同一个条目每次都是同一个别名
- 封面一律不请求、不显示，只留占位块，也就不会往图床拉图
- 简介、别名、导演、声优换成占位文案，下载记录里的路径只留文件名
- 只有「葬送的芙莉莲」保持正常显示，用来对照排查某个条目显示异常时到底是数据问题还是渲染问题

搜索结果默认**不受遮蔽**（「调试模式下搜索结果保持正常显示」默认开启）：要排查的条目本来就得先靠搜索找出来，所以搜索页保留真实名称和封面。关掉这个开关，搜索结果也会换成别名与空封面。

关掉调试模式后立刻恢复真实内容，首页会自动重新拉一次数据；搜索、分类片库、详情的缓存同时作废，避免还显示着旧的别名。

## 多语言

语言文件放在 `ttdm/locales/`，一种语言一个 JSON，键是中文原文、值是译文（和 Minecraft 的语言文件一个思路，只是键直接用中文，方便对照）：

```json
{
  "@name": "English",
  "首页": "Home",
  "第 {page} 页 · 本页 {count} 部": "Page {page} · {count} titles"
}
```

- 新增语言：复制 `en_US.json` 改名成 `<代码>.json`（比如 `ja_JP.json`），把 `@name` 的值改成这种语言的自称，再逐条翻译；设置页的语言下拉框会自动出现这个选项
- 漏翻的条目自动回退中文，不会报错也不会空白
- 代码里的静态文案保持中文即可，控件显示时会自动查表替换；页数、集数这类运行时拼接的文案用 `tr("…{n}…", n=…)` 显式翻译
- 切换语言是即时的：静态文案就地重译，卡片、集数、下载记录这些动态内容会重新生成

## 数据与缓存

- 设置、观看记录、下载记录、镜像列表：`%LOCALAPPDATA%\TianTianAnime\settings.json`
- 封面缓存：`%LOCALAPPDATA%\TianTianAnime\cache\images`
- 播放分片缓存：`%LOCALAPPDATA%\TianTianAnime\cache\hls`（上限在设置里改，默认 8 GB）
- 分类片库的缓存只在内存里，重启程序即清空
- 运行日志：`%LOCALAPPDATA%\TianTianAnime\logs\app.log`

改名不影响数据目录：配置文件仍在 `TianTianAnime` 下，升级后原有设置、记录和缓存都还在。

## 打包

想自己做 exe：

```
python -m PyInstaller --noconfirm --clean --windowed --name Kelire ^
  --icon app.ico --collect-all yt_dlp --collect-all imageio_ffmpeg --add-data "ttdm/locales;ttdm/locales" run.py
```

产物在 `dist/Kelire/`（约 271 MB），可以整个目录拷走用。`app.ico` 已经放进仓库；需要重新生成时用 PySide6 画一遍再转 ico 即可。加了 `--add-data` 之后语言文件会一起打包，否则 exe 里只有中文。

## 已知情况

- 站点对单连接限速明显，程序用 24 路并发分片把带宽跑满；下载尾部（96% 以上）偶尔会掉到几十 KB/s，是站点对收尾分片的限速，等一会儿会自己结束
- 拖进度条基本是秒跳：目标分片会被优先下载，实测从 4 秒拖到 92% 约 1 秒恢复播放；如果网络抖动导致卡住，程序会自己重连一次本地清单
- 预加载只用 4 个连接、只拉每集开头一小段，正常不会影响正在播放的那一集；如果网络本来就紧张，可以在设置里把「预加载集数」调小或者关掉不用
- 数据目录写的 `%LOCALAPPDATA%\TianTianAnime`，如果该位置不可写（比如在某些受限沙箱里），会自动退到系统临时目录下的同名目录，程序照常能用
- 部分线路本身已经失效，切到别的线路或者点顶栏线路标签重新测速
- 分类片库的缓存是内存缓存，切到别的分类再回来不会重新请求；想拿最新数据就点「刷新」
